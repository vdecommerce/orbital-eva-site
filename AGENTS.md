# Orbital EVA website
Static Dutch project showcase. Source in src/, build with npm run build.
Use actual Unreal screenshots, preserve NASA attribution and distinguish Earth ISS from the fictional Mars station.
No tracking, accounts or cookies. Do not imply headset validation until physical checks pass.
Check desktop/mobile, keyboard interaction and reduced motion before deployment.

Publication: GitHub Pages from main:/docs. Run npm run pages to validate/build and refresh the tracked docs/ snapshot. dist/ remains ignored.
