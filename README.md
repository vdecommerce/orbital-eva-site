# Orbital EVA website

Nederlandstalige presentatie van het PC-VR-project met beelden uit het Unreal-project. Aarde/ISS en het fictieve Marsstation, beweging, inspectiemissie en projectstatus.

Geen framework, tracking of externe fontrequests. Toetsenbordbediende bestemmingstabs, fotodialoog, lichte/donkere weergave en reduced-motion-ondersteuning.

npm run check
npm run build

npm run pages bereidt de gepubliceerde snapshot in docs/ voor. GitHub Pages publiceert main:/docs, zonder aparte workflowrechten. Bronwijzigingen staan in src/; docs/ wordt uitsluitend na controle bijgewerkt. Beeldcredits staan op de pagina. Publiceer geen ruwe Eagle-textures of privéconfiguratie.
